# Maji Ndogo: From Water Crisis to Data-Driven Solutions
 
An end-to-end data project completed as part of the **ALX Data Engineering
program**, using **SQL, Power BI and Python**.
 
## About the project
 
**Maji Ndogo** is a **fictional country** facing a severe water crisis. A new
government wants to fix it using data instead of guesswork. Over the project,
I work as part of the data team, following the problem from start to finish:
exploring a raw national survey, uncovering errors and corruption, planning
and budgeting repairs, tracking the project as it happens, and finally
preparing the country's agricultural data for machine learning.
 
The story is fictional, but the work is realistic: messy data, inconsistent
records, changing requirements from decision-makers, and the need to validate
data before trusting it.
 
## Project structure
 
```
maji-ndogo-project/
├── 1_sql/        Data exploration, cleaning and analysis in MySQL
├── 2_power_bi/   Interactive reports and dashboards in Power BI
├── 3_python/     Data cleaning, analysis, validation and a data pipeline in Python
└── README.md
```
 
Each folder has its own README with more details.

1. SQL

The project begins with SQL, where the raw water survey data is explored, cleaned, and analyzed.
This stage focuses on:
Understanding the database structure
Identifying and correcting data quality issues
Analyzing water access and infrastructure
Producing insights from the survey data

2. Power BI

Turning the analysis into interactive reports and dashboards.
This stage focuses on:
Data modeling
DAX measures
Data visualization
Communicating findings through reports and dashboards
Tracking the progress of the water improvement project

3. Python

With water access improving, the next challenge was agriculture.
This stage includes:
Data ingestion
Data cleaning and processing
Exploratory data analysis
Automated data validation
Statistical hypothesis testing
Building a reusable Python data pipeline
